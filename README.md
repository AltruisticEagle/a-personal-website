# a-personal-website
A personal website I'm making as part of the Stardance Challenge.

# AI use declaration
AI was not used to write any code as part of this project; I used it to assist me in brainstorming trivial and non-technical matters, such as "should I include this topic as part of the page". I did use it on some occasions to debug annoying instances of bugs, such as when I lost the better part of half an hour not being able to figure out why the browser was stubbornly refusing to read the correct styles.css stylesheet after verifying myself there was nothing wrong anywhere. (On that note, it took only a forced reload to solve the problem. It was very annoying when it just disappeared.)

In any case, I can proudly claim that every thought on the pages was typed out by human hands on a faltering keyboard. I really need a new one. 

# Structure
The link to the website is at ```www.jasonfang.com```.

There are 7 pages to this very basic website, structured vaguely according to my resumé.

The first page is about my academics. You know, the stuff about school, a long thought about what courses I'm doing and about what I want to achieve at school.

The second page is about my accolades. Just a short list of awards I've gotten, it's honestly not that impressive compared to a lot of people I presumably should be comparing myself to, also feel free to have a look. 

The third page is about my coding experience. Credit to Bootstrap; I recalled that I could use its accordion table feature (which I had experimented with previously in my free time) to pretty cohesively build a narrative of my experience in the domain. The section is divided by coding language. 

The fourth page is about my debate experience. I did some math and scrolled through some old results, and I made a table of some of the most important statistics of my years in the activity. A career summary, if you will; this page also contains some philosophial takeaways I derived from the activity.

The fifth page are some brief initial thoughts about TKS. The program hasn't started for me yet, so it's a short page. Hopefully it brings me luck. 

The sixth and final page is about myself. I put that in for old times' sake, and it just contains some random things I remember from back then.
